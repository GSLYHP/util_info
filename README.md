**Meta Description**

  是面向开发者和日常办公场景的在线工具箱，提供 JSON 格式化、文本对比、时间戳转换、AES/RSA 加解密、MD5 哈希、省市区查询及测试数据校验等实用功能。


## JSON 格式化与数据处理

爱梅库提供功能完善的 JSON 格式化工具，支持代码美化、单行压缩、层级浏览、文件上传以及转义字符处理。对于 Java Map 风格的键值字符串、嵌套 JSON 和包含时间戳的数据，也可以进行智能识别和转换。

无论是排查接口返回值，还是整理日志内容，都能显著提升处理效率。

## 文本对比与时间戳转换

文本对比工具可以逐行分析两段内容，清晰标记新增和删除部分，适用于代码检查、配置文件核对和文档差异分析。

时间戳转换工具支持 Unix 秒级、毫秒级时间戳与标准日期时间双向转换，方便开发者定位日志时间和处理接口参数。

## AES、RSA 与 MD5 工具

爱梅库内置密码学工具套件，支持 AES 对称加密、RSA 非对称加密以及 AES + RSA 混合模式。用户可以根据联调需求配置加密模式、填充方式、密钥和输出格式。

MD5 工具支持生成标准 32 位大小写哈希值，并可在获得授权的情况下通过后端接口查询测试数据，用于系统联调和数据核验。

## 行政区划与测试数据校验

系统提供省、市、区县行政区划查询，支持级联选择、模糊检索和接口配置，适合地址表单、业务系统和地区数据维护场景。

此外，平台还提供身份证规则解析、虚拟档案生成和银行卡 Luhn 校验等测试辅助功能。这些功能仅适用于软件开发、测试环境和规则验证，生成数据不得用于真实身份认证、支付交易或其他违规用途。
